# Intel-Data-Center-Energy-Analysis

## Project Overview
Developed an interactive Tableau dashboard to evaluate potential U.S. locations for an Intel data center using regional energy generation and demand data. The analysis identified areas with reliable energy supply, strong renewable-energy generation, stable demand, and potential cost advantages.

## Business Question
Which U.S. region offers the strongest combination of energy surplus, renewable-energy availability, demand stability, and generation reliability for a new Intel data center?

## Tools Used
- Tableau
- Microsoft Excel
- Data visualization
- Data analysis

## Analysis Performed
- Calculated net energy production by region
- Compared demand and net generation across selectable time periods
- Measured renewable energy as a percentage of total generation
- Analyzed energy-source composition by region and balancing authority
- Examined hourly changes in wind-energy generation in California
- Created an interactive dashboard with region and time-period filters

## Key Skills Demonstrated
Calculated fields, parameters, filters, dual-axis charts, line charts, bar charts, treemaps, dashboard design, data storytelling, and business recommendations.
